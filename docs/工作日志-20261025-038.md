## 3. 代码改动

### 3.1 `src/yosys-069/passes/pmux/pmux_opt.cc`

- `choose_split_plan()` 改为混合策略：
  - 组合数不超过 `100000` 且单根选项不超过 `1000000` 时，完整精确搜索；
  - 超过预算时，最多 8 轮坐标下降；
  - 两两交换最多 3 轮，候选预算 `120000`，超预算自动关闭；
  - 使用 generation-stamp 节点表计算共享成本；
  - 日志区分 `split plan exact=...` 与 `split plan local=...`。
- 删除失效的 `prefer_plain_ff_flow` 判断，避免与新的宽 ROM 结构保护重复或冲突。
- 在常量 ROM lowering 增加保护：
  `mem.width > 128 && addr_bits > 5` 时回退 `memory_map`/ABC。
- verbose 模式增加 ROM 的 order/split/estimate 以及 fold/模块阶段计时；不影响默认
  综合结果，仅用于后续定位性能回退。

### 3.2 `scripts/probe_const_pmux_matrix.py`

- 新增 `--full-width-tables`：用 SHA-256 按输出位生成确定性数据；
- 旧 32 位 LCG 模式保留，已有小宽度结果仍可复现；
- 输出 JSON 记录 `data_model`，避免把两种数据模型混为一谈。
