**评分**：功能正确性 10，面积优化 40（20% 为满分线），算法效率 30

任一用例不等价则功能性得 0 分，其余各项一律不计分。

**环境要求**：组委会指定 **Yosys 0.68**。

## 三、必须知道的关键结论

### 1. 只有特定写法才生成 `$pmux`

实测结论，直接影响测试用例怎么写：

| 写法 | 结果 |
| --- | --- |
| `case (sel)` 多分支对常量比较 + `default` | **生成 `$pmux`** |
| 单个 case 分支里写多个值，如 `4'd1, 4'd3: y = a;` | **生成 `$pmux`** |
| `case (1'b1)` 配 `sel[i]` 位选条件 | 不生成，得到 `$mux` 树 |
| 三目运算符链、独立 `if` 链 | 不生成，得到 `$mux` 树 |

**更重要的语义差别**：位选条件那两种写法和 `$pmux` 语义不同，
它们表达的是「多根独立使能线，可同时有效」，而 `$pmux` 是「一个值选一路」。
两者不能直接比单元数（这里曾经写错过一次，已修正）。

### 2. `$pmux` 的端口语义

从官方源码 `pmux2shiftx.cc` 第 66 至 73 行确认，不是凭印象：

| 端口 | 含义 |
| --- | --- |
| `A` | 默认值，所有选择都不成立时输出 |
| `B` | 各路数据拼接，按输出位宽切片，每片一路 |
| `S` | 选择信号 |
| `Y` | 输出 |

### 3. 待优化的「原始结构」不止一个单元

以一个 8 位宽、8 选 1 的用例为例，`proc` 之后的结构是：

```
7 个 $eq（sel 与常量 7..1 比较） + 1 个 $logic_not（等价于 sel == 0）
                    |
        8 个信号接到 $pmux 的 S 端口
```

注意工具已经会自动优化：8 路比较里有 1 路用 `!sel` 代替了 `$eq`。
识别工作要把 `$pmux` 和产生选择信号的逻辑一起圈出来，不能只看那一个单元。

### 4. 优化空间的量化（Yosys 0.68 实测）

8 位宽、8 选 1 的同一个功能：

| 流程 | 门级单元数 | 相对默认 |
| --- | --- | --- |
| Yosys 默认综合流程 | 132 | 基准 |
| 额外调用一次现成的 `pmuxtree` | 103 | 缩减 22% |
| 等价功能的显式选择树 | 56 | 缩减 58% |

结论：现成的一步只能拿到 22%（刚过满分线），从 103 到 56 还有约 46% 的空间
必须自己写算法。这是整个选题的价值所在。

### 5. 版本必须锁死

同一组用例在 0.69 上重跑，默认流程和理论上限完全一致，但两处不同：
展平后 103（0.68）对 88（0.69），`pmux_nested` 112 对 106。
说明上游仍在优化这个方向。所有实验必须固定 0.68 并记录版本号。

## 四、踩过的坑（不要再踩）

1. **Windows 上编译不了 Yosys 插件**。现成的 OSS CAD Suite 有头文件，
   但没有编译链、没有 `lib/yosys/yosys.exe.a` 导入库，而且它是 MinGW 构建的。
   官方只正式支持 Linux 和 macOS，文档里 MSYS2 那一节被注释掉了并写明
   "Not that I can get this to work"，Cygwin 那节也明确建议改用 WSL。
2. **EQY 在 Windows 上缺 GNU make**。前四步（读 gold、读 gate、合并、分区）都能过，
   最后 `make -f strategies.mk` 失败。绕过办法是直接用 bash 跑生成的 `run.sh`，
   结论一样。要全自动就得装 make 或转到 macOS 或 Linux。
3. **`.eqy` 配置文件里写中文注释会报 GBK 解码错误**。EQY 用系统默认编码读配置，
   中文 Windows 下必须设 `PYTHONUTF8=1`。macOS 上一般不会有这个问题。
4. **`.eqy` 的 strategy 段必须有 `use` 行**，例如 `[strategy sat]` 下面要写 `use sat`。
5. **环境脚本只在根变量未定义时才设置根目录**。同一进程里想切换版本，
   必须先清掉 `YOSYSHQ_ROOT`，否则会继续用旧版本。这个坑导致一次对照实验
   两个版本跑出同样结果，白折腾一轮。
6. **`yosys -q` 会连 `stat` 的输出一起吞掉**，做统计时不要加这个参数。
7. **在 PowerShell 里写 Yosys 命令要注意 `$` 转义**。`$pmux`、`$eq` 会被当成变量，
   要用单引号包裹命令串。
8. **Word 打开着的 DOCX 无法被覆盖写入**，生成文档前先确认文件没被占用。
