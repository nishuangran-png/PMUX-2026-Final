## 新增结构规则

1. 稠密译码 PMUX 继续改写为总线控制的 mux tree；默认树顺序按选择总线
   宽度自动选择，`<=2` 位低位优先，更宽高位优先。
2. 同一 PMUX 的所有叶子若是同一种可因子化运算符，则先选操作数、后执行
   一次运算符；适用于 XOR、ADD、SUB、AND、OR。
3. 深链守卫由“只要有深 PMUX 就跳过”改为“直接 PMUX 前驱彼此独立才允许
   放宽”。串联反馈链仍跳过。
4. 所有规则只读取单元类型、端口连接、位宽和数据锥；不读取 case 名、
   top 名或源文件名。
5. 默认行为不依赖 `PMUX_*` 环境变量；这些变量只用于消融实验。
