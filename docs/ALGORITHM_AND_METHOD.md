# PMUX optimization method

`pmux_opt` recognizes RTLIL structures including:

- `$pmux` selection networks;
- priority `$mux` chains;
- sparse partial-update PMUX patterns;
- constant ROMs;
- shared decoders and enable terms;
- two-dimensional PMUX selection matrices.

The pass performs only transformations whose selection relation is established
from the RTLIL connectivity and constants. It never reads case names, source
file names, or benchmark identifiers.

The main transformations are:

1. dense-decoder PMUX lowering to bus-controlled mux trees;
2. inverse-code sharing and two-dimensional matrix transposition;
3. priority-chain normalization;
4. sparse branch elimination;
5. common enable and comparison factoring;
6. constant-ROM lowering;
7. fixed-point iteration.

The candidate calls the submitted unified ABC9 script:

```text
&scorr
&sweep
&dc2
&dch -f -r
&if -W 300 -a -v
```

Temporary LUTs generated by constant-ROM lowering are materialized before the
remaining standard logic mapping. This preserves the structure for the
subsequent `pmux_opt -fold_luts` stage.
