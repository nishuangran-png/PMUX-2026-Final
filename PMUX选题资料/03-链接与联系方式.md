## 开发工具

- Yosys 源码仓库：https://github.com/YosysHQ/yosys
- Yosys 命令参考：https://yosys.readthedocs.io/en/latest/cmd_ref.html
- Yosys 工具文档：https://yosyshq.readthedocs.io/en/latest/tools.html
- EQY 形式等价验证：https://yosyshq.readthedocs.io/projects/eqy
- 选题指南里给的 Yosys 参考文档：https://yosyshq.readthedocs.io/en/latest/tools.html#yosys

macOS 上装 Yosys 的几种方式：

```
brew install yosys
```
或者从源码编译（如果要用最新 pass，建议源码编译）：
```
git clone https://github.com/YosysHQ/yosys
cd yosys && make config-gcc && make -j
```
